# Milanto | Deep Learning Specialist for Conservation & Sustainability 🌍

Leveraging Deep Learning to solve critical challenges in biodiversity, precision farming, and climate resilience. I'm passionate about building artificial intelligence (AI) and deep learning models to support ecological and biodiversity monitoring, climate science, remote sensing, medicine, Agriculture, and precision farming.

## 🔬 Featured Projects

### 🦇 [Bayesian Bioacoustics](https://github.com/milanto-hery/bayesian-bioacoustic)
**Predictive Uncertainty** and **Species-Agnostic frameworks** for robust, generalized ecological monitoring using deep learning.

### 📷 [Edge-AI Monitoring](https://github.com/milanto-hery/bird-detector-pi)
**Real-time Field Surveillance with Computer Vision and IoT (Telegram) integration** deployed on Raspberry Pi hardware.

### 🎧 [Compressed Sensing Audio](https://github.com/milanto-hery/compressed-sensing-audio)
**High-fidelity audio reconstruction for hardware-constrained environments**, applying advanced L1-minimization algorithms to sparse signals.
